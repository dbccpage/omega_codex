# Omega Codex Derivation DAG (`dag/derivation_dag.json`)

This directory contains the machine-auditable directed acyclic graph ([`derivation_dag.json`](derivation_dag.json)) classifying every derivation step, admission boundary, and downstream target in the `omega_codex` program into three epistemic buckets:

1. **`DERIVED` (24 nodes)**: Checked in constructive Lean 4.33.0 (`lean/*.lean`, 350 theorems across 9 modules with SHA-256 verification receipts in `docs/*_verification.json`, 100% theorem coverage in the DAG) and/or Python 3 standard-library check scripts (`audit/2026-11-05_minimal_chain/*_checks.py`, `scripts/*.py`). Nodes whose checked theorems depend on an unconstructed bridge or supplied model assumption (`DER-12`, `DER-22`, `DER-23`) carry `status_detail: "DERIVED_CONDITIONALLY"` and explicit `requires_admission` edges from their upstream `OWED` bridge nodes (`OWE-07`, `OWE-08`, `OWE-12`, `OWE-13`).
2. **`OWED` (12 nodes)**: Explicit host substrate admissions (`S0`–`S5`), post-seal unfreezing mechanism choices (`M1`–`M3`), and open bridge obligations (`OWE-05` through `OWE-10` and `OWE-12` through `OWE-13`, covering `PG-R-GAP`, `N21` endogenous internal witness acquisition/invocation, `N19`–`N20` ten-stick carrier and period-4 necessity, `L1-R-RESIDUAL-TO-WEIGHTS`, `N23`/`N25`/`N26` infinite/continuum completion, `OQ-08` prose `WDP-CH01-D03` to pinned legacy `Represented`/`Horizon` bridge, and `N22` multi-round retention capacity scaling and repair persistence).
3. **`IMAGINED` (10 nodes)**: Planned downstream Cosmos extensions still to come (`IMG-01` through `IMG-10`): higher $k$-simplex WDP cohomology, causal-diamond observer functors, $\ell_1$-to-$\ell_2$ Parseval phase bridge, finite quantum mechanics (Born rule, finite Gleason frame functions, CPTP channels), MUBs and entanglement, discrete Noether currents, finite lattice gauge sectors, simplicial Regge gravity, finite constructor theory, and self-hosting Cosmos metatheory.

## Validation Commands

Run the standalone validator and unit test suite from the repository root:

```powershell
python scripts/validate_derivation_dag.py --run-checks
python -m unittest discover -s tests -p "test_*.py" -v
```

The validator checks:
- Top-level schema, `admissions_catalog`, Claim Hygiene scope fields, and absence of forbidden hype terms across all node titles, statements, and edge notes.
- Exact agreement between each Lean-backed node's `lean_file`, `lean_module`, `receipt_json`, and `lean_inventory` entry (rejecting mismatched source/receipt pairings or missing `lean_module` even when files exist), plus SHA-256 source and `direct_imports` match, axiom compliance (`propext` / `Quot.sound` only, zero `Classical.choice` or `sorryAx`), theorem-count parity across all 9 Lean modules (`350` total theorems), 100% surjective theorem coverage, and 100% reference coverage across `N00`–`N33`, `OQ-01`–`OQ-08`, and `RT-01`–`RT-12`.
- Exact admission resolution and edge accounting: every identifier in `unpriced_inputs_or_admissions` must resolve in `admissions_catalog` to an `OWED` (or `IMAGINED` for `IMG-*`) provider node's `defines_admissions`, every `DERIVED_CONDITIONALLY` node must depend on at least one `OWED` bridge obligation (`OWE-05`–`OWE-10`, `OWE-12`–`OWE-13`), and every node requiring an admission from an `OWED` provider `P != nid` must have a matching `requires_admission` edge `P -> nid` (removing any required admission edge fails closed even if a compensating edge preserves total edge count).
- Epistemic edge discipline and strict topological acyclicity (Kahn's algorithm over all 46 nodes and 104 directed edges).
- **Scope boundary**: Structural validation confirms artifact integrity, theorem-to-receipt binding, and declared admission-edge consistency; it does not substitute for human mathematical review of whether declared premises faithfully reconstruct a prose source claim.
